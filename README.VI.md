# Đế Chế Web VN

**Mở game ngay:** https://tdumii.github.io/aoe-web-browser-vn/

Trang chủ **chuyển hướng trực tiếp** đến https://aoe.skyvalley.me/ (Sky Farmer) để chơi Age of Empires 1 / Rise of Rome trên web mà không cần tải hoặc chọn file EXE.

## Lưu ý

- Đây là shortcut tới **dịch vụ game của bên thứ ba**, không phải bản AOE do repo này tự host. Code gameplay, đồ họa, âm thanh và máy chủ đều thuộc dịch vụ Sky Farmer và các chủ sở hữu liên quan.
- Trang chủ không Việt hóa giao diện **trong game** hoặc tăng độ phân giải tài nguyên game. Việt hóa chỉ tồn tại trong launcher cũ của dự án.
- Nếu truy cập không tự động chuyển, vào trực tiếp https://aoe.skyvalley.me/.
- Bản chạy file AOE cá nhân vẫn được giữ tại https://tdumii.github.io/aoe-web-browser-vn/launcher.html.
- Phiên bản launcher cũ dựa trên [WindowsAppPlayer](https://github.com/bassdrum4/windowsappplayer) / Boxedwine / Wine và chưa xác nhận tương thích với AOE.
- Không sao chép lại mã nguồn hoặc dữ liệu trò chơi từ Sky Farmer. Không liên kết với Microsoft, Ensemble Studios hoặc Sky Farmer.

## Dành cho người phát triển

Chạy `npm run setup` và `npm start` để dùng launcher cũ tại `http://localhost:8097/launcher.html`.

Mã nguồn launcher cũ được giữ cùng `LICENSE`, `NOTICE.md`, và các thông tin ghi công upstream.
